## Overview of the Experiment

Main goal was to characterize the intensity of traditional resistence training vs cluster resistance training.

- Traditional Resistance Training (TRT): Involves performing a set number of repetitions continuously until the set is complete, followed by a rest period.
- Cluster Resistance Training (CRT): Involves breaking a set into smaller clusters of repetitions with short rest intervals in between, allowing for brief recovery periods during the set.

Question: Are there differences in heart rate response between traditional and cluster resistance volume-matched protocols?

## Experiment Details

- Participants: 10 college students
- Cross-over design
    + Each participant complete both the traditional and the cluster protocols
    + Randomized (flipped a coin) which protocol was completed first
    + One week washout period between protocols
    + Measured heart rate, before and after exercise

## Data Dictionary

- ID : Participant identifier
- Condition: TRAD or CLU (traditional or cluster)
- Time: PRE or POST (before or after exercise)
- HR: Heart Rate (in beats per minute)
